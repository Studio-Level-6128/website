# Studio Level 6128

A static studio homepage. The logo and monochrome game previews are local assets; no build step or JavaScript is required.

Preview from the repository root with `python3 -m http.server 8000`, then open `http://localhost:8000/`.

To publish, commit and push the site (including the supplied GIF and `assets/`) to `main`. In **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**. The project site address is `https://studio-level-6128.github.io/website/`.
